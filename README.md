# Who Watches the Watchers? — PLS 419

Static research website about AI, public procurement, and accountability in Kazakhstan.

## Publish with GitHub Pages
1. Create a public GitHub repository (e.g. `who-watches-the-watchers`).
2. Upload `index.html`, `styles.css`, `script.js`, `data.json`, and this README **to the repository root**.
3. Open **Settings → Pages** in GitHub, choose **Deploy from a branch**, **main**, and **/(root)**, then Save.
4. When GitHub reports the live URL, open and test it. The format is `https://YOUR-USERNAME.github.io/REPOSITORY/`.

All chart figures are transcribed from an OCP publication. The budget slider is an illustrative scenario, not live procurement data. This website is a research proposal, **not** an operating AI procurement detector.
